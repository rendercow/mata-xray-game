마타의 X-RAY 탐지 대작전 v1.3.1

실행 방법
1. ZIP을 풀고 폴더 구조를 유지한 채 index.html을 Chrome 또는 Edge에서 실행합니다.
2. 브라우저 정책 때문에 효과음은 게임 시작 또는 첫 클릭 이후 정상적으로 들릴 수 있습니다.

v1.3.1 주요 변경점
- 탐지견 머리/몸통 때문에 클릭이 막히는 기능 제거
- 캐리어 내부 물건 배치 범위를 보정해 캐리어 밖으로 튀어나오지 않도록 수정
- 캐리어 내부 클리핑을 적용해 시각적으로도 물건이 바깥으로 보이지 않도록 수정
- X-ray 시각효과 추가 강화: 보조 스캔 빔, 노이즈 라인, 내부 광택, 비네트 강화
