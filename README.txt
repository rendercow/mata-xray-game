마타의 X-RAY 탐지 대작전 v1.3.4 — 모바일 가로화면 테스트 UI

사용 방법
- PC: index.html을 열면 기존 PC용 UI가 그대로 표시됩니다.
- 모바일: 게임 시작을 터치하면 전체화면 전환을 시도하고, 가능하면 가로 방향을 잠급니다.
- 기기의 브라우저 정책에 따라 전체화면이나 회전 잠금이 제한될 수 있으니 필요할 때 수동으로 가로 회전하세요.
- 화면 위쪽에 시간/점수/콤보, 아래에 시작/일시정지/사운드/전체화면 버튼이 표시됩니다.
- 가로화면에서는 추가 스크롤 없이 플레이하도록 화면 크기를 맞췄습니다.

유지된 기능: v1.3.3 PC 안정성 보완, 탐지견 경고 및 사운드, 캐리어 겹침 클릭, X-ray 영상 효과.
