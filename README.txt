마타의 X-RAY 탐지 대작전 v1.4.0

변경 사항
- 게임 종료 시 TOP 5 진입 여부에 따른 두 가지 미소 사진 팝업
- 점수가 5위 내 진입하면 8자 이내 이름/닉네임 등록
- 상위 5개 기록을 이 브라우저의 localStorage에 저장(다른 기기와 공유되지 않음)
- PC 및 모바일에서 랭킹 화면 조회 가능
- 기존 v1.3.5 게임 플레이 및 모바일 UI 유지

실행: ZIP 전체 압축 해제 후 index.html 실행 또는 GitHub Pages 업로드
주의: 온라인 공통 랭킹은 별도 데이터베이스 연동이 필요합니다.
